ChaosOps 离线安装说明

Server 安装（V2）

tar -xzf chaosops-free-v0.1.0-linux-x86_64.tar.gz
cd chaosops-free-v0.1.0-linux-x86_64
sudo ./install-server.sh

安装器会自动创建 /opt/chaosops 的 bin/data/config/logs 目录结构。

Agent 安装（Linux）

sudo ./install-agent.sh --server-url=https://your-server --install-key=ik_xxxx

Agent 安装（Windows）

.\install-agent.ps1 -ServerUrl "https://your-server" -InstallKey "ik_xxxx"
install-agent.bat https://your-server ik_xxxx

内置 Python：本包自带免安装 Python 运行时（python-build-standalone 构建，PSF 许可）。 目标机无 python3.10+ 时，安装器自动使用包内运行时（部署到安装目录）， 不污染系统 Python；系统已有 python3.10+ 时优先使用系统解释器。

注意：Windows 版 Agent 安装需要联网。捆绑的离线 wheels 在 Linux 上构建， 其中的二进制包（如 psutil）为 Linux 专用（manylinux），无法在 Windows 安装；安装器会自动 识别并改用捆绑的纯 Python 包 + 从 PyPI 下载 Windows 专用包。Linux Agent 安装则完全离线。
